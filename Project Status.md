# Photoshop UXP Batch Mockup Plugin

## Purpose

Provide a reusable Adobe Photoshop UXP plugin that automates the creation of product mockups from multiple artwork files.

The project serves as both a practical production tool and a public portfolio example of Robert's Photoshop automation and workflow-development experience.

## Desired Outcome

Maintain a professional, publicly presentable project that:

- Automates repetitive Photoshop mockup production.
- Processes multiple artworks across multiple templates.
- Reduces manual product-image work.
- Supports Etsy and other listing workflows.
- Demonstrates JavaScript, Adobe UXP, and workflow-automation skills.
- Supports Robert's Fiverr service offerings.
- Can contribute to the larger MockupWorkflow.Platform project.
